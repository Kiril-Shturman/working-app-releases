# Working App — сборки

Здесь публикуются только готовые сборки приложения. Исходный код — в приватном репозитории.

## Установка на macOS

Вставьте в Терминал:

```bash
curl -fsSL https://github.com/Kiril-Shturman/working-app-releases/releases/latest/download/install-macos.sh | bash
```

Установщик скачает сборку под ваш Mac, проверит контрольную сумму и подпись, поставит приложение в «Программы» и запустит его. При первом запуске macOS попросит пароль администратора — он нужен ядру VPN для работы TUN.

Поддерживаются Mac на Apple Silicon (M1 и новее) и на Intel — сборка универсальная.
